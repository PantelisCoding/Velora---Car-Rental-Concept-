# Velora — premium car rental website concept

A responsive, vanilla HTML/CSS/JavaScript redesign of the supplied car-rental template.

## Run

Open `index.html` in your browser, or use VS Code Live Server. No npm packages are required.

## Car images

Copy the existing `car-2.png` through `car-10.png` assets from your original project into this folder alongside `index.html`. A generic remote fallback photo displays when an asset is unavailable.

## Before launching a real business

1. Set `CONFIG.businessEmail` in `script.js` to your verified business reservations mailbox.
2. Replace the Velora brand, location options, vehicle inventory, photos, example prices, service descriptions and demo disclaimers with accurate business data.
3. Confirm all photo licensing; two decorative images are hosted via Unsplash and require a connection.
4. Replace `mailto:` enquiries with a secure backend for inventory availability, verified reservations, payment, user accounts, transactional emails, fraud protection and personal-data handling.
5. Add real terms, privacy and cookie disclosures, rental agreements, insurance/deposit policies and contact details before publishing.

### What already works

Mobile navigation, vehicle rendering, category filtering, sorting, location filtering, date validation, booking-enquiry dialog, email enquiry composition (once configured), FAQ accordions and responsive layouts.

**This is a polished functional front-end concept, not a live booking/payment system.** Vehicle-location availability and prices are sample data and are not checked against a real inventory.
